## 💾 Local Git Workflow

### Daily Work

```bash
# Check status
git status

# Create feature branch
git checkout -b feature/user-authentication

# Make changes, then stage
git add .

# Commit
git commit -m "feat: implement JWT authentication"

# Push to GitHub
git push origin feature/user-authentication

# Switch back to main
git checkout main

# Pull latest changes
git pull origin main
```

### Update Token (when it expires)

Your token will expire after 90 days (or based on your setting). To update:

```bash
# Update stored credentials
git config --global credential.helper osxkeychain

# Next push will prompt for new token
git push
# Username: hemantmangwani
# Password: <new token>
```
